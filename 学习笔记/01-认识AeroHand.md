# 第一课：认识 AeroHand

## 今天的目标
能说出机械手怎么动、程序怎么控制它，以及训练在其中处于什么位置。

## 1. 它是什么
Aero Hand Open 是一个五指、绳驱动的开源机械手。电机拉动类似肌腱的绳，绳带动手指运动。官方说明它有 16 个关节、7 个自由度：关节数是可弯折的位置数量，自由度可以粗略理解为能独立控制的运动方向数量；它们不是一回事。

资料：[官方项目](https://github.com/chestnut-robotics/aero-hand-open)。

## 2. 指令怎样让手动起来
电脑上的 Python 程序 → 通信连接 → 控制板上的固件 → 电机拉动绳 → 手指运动。

Python SDK 是官方提供的工具包，能帮你调用控制功能；固件是运行在控制板上的程序。实际连接方式和指令需看具体硬件及官方 SDK 文档，暂不假设你的设备配置。

## 3. 训练在哪里
让手握拳不一定需要训练：可以由人预先写好动作指令。

训练的另一条路线是强化学习：在模拟器里，让控制程序反复尝试动作，根据是否接近目标获得奖励或惩罚，逐步学习策略。策略可以理解为“根据当前情况，决定下一步动作的规则”，它可以由神经网络表示。训练完成后，把学到的策略用于推理；能否直接用于真手还取决于硬件、部署方式和仿真与现实的差异。

和 YOLO 对照：YOLO 常见输入是图片，输出是检测结果；机械手控制策略的输入可以是关节状态、物体位置等，输出可以是控制动作。具体输入输出由任务决定。

## 4. 项目地图
- `hardware/`：机械与电路相关资料。
- `firmware/`：设备端固件。
- `sdk/`：使用 Python 等方式控制的工具与示例。
- `ros2/`：机器人软件通信与集成相关内容。
- `sim_rl/`：仿真和强化学习相关内容。

建议先认识手和控制链路，再看 SDK 示例与仿真，然后学习强化学习、训练和部署。是否先接触真机取决于你是否有设备。

## 5. 自测
1. 手指为什么会弯？提示：电机、绳、手指。
2. 写死一个握拳动作需要训练吗？
3. YOLO 常见输出与机械手控制策略的输出有什么区别？

参考答案：1. 电机拉动绳，绳带动手指。2. 不一定，预设动作可以不训练。3. YOLO 常输出检测结果；控制策略输出下一步控制动作，具体形式由任务决定。

## 接下来要确认
是否有实物或只有电脑；Python 和 C/C++ 基础；目标是控制机械手、复现训练还是两者都要；电脑系统及显卡。根据情况安排第一项动手操作。
